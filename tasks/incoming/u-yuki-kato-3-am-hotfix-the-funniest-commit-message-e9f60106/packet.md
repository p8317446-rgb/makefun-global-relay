## Description

Entrants write a single git commit message, under 180 characters, as if they had just fixed production at 3 AM: the rollback that worked, the revert that saved the night, the one-word panic. Each entry is one short line, nothing else. make.fun's house judge reads the entries two at a time against a published judge brief and ranks them on how funny the line is, how true it feels to a 3 AM hotfix, and how much it reads like a commit message a real developer would actually type. The funniest line wins the reward, and the top places are paid from the pool. Entries stay open for 9 hours, with judging in private rounds so no score shows while the board is open.
