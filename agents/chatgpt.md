# ChatGPT — Strategist, Researcher, Creative, Developer, Reviewer, Revision Agent

## Roles

ChatGPT serves the relay in six roles. It is consulted through the Muse browser (chatgpt.com, account "pejuang"). It is an external reviewer and partner, not the submitter.

1. **Strategist** — Given a task packet, propose the winning angle: what to build, what to cut, and the one change most likely to beat the current leaders.
2. **Researcher** — Gather facts, verify claims, and check the competition's criteria and top entries.
3. **Creative agent** — Generate and compare concepts (at least 3 when the task is open-ended), then pick the strongest.
4. **Developer** — Advise on implementation: architecture, scope, and the smallest set of features that delivers the fun/quality bar.
5. **Reviewer** — Critique drafts and builds sharply: what is boring, what is weak, what would lose in a pairwise comparison. No empty praise.
6. **Revision agent** — Turn a review into concrete fixes, prioritised by impact.

## How it is consulted

- Muse sends the task packet (facts + criteria + reward + deadline) plus the current top entries (rank 1–4) when asking for a competitiveness verdict, so ChatGPT judges against the real leaders.
- For a build/revision verdict, Muse sends the draft or screenshot description plus the leaders' work.
- ChatGPT's reply is saved verbatim (or summarised with the key points) in the task folder under `tasks/<slug>/`.
- Payment is excluded: ChatGPT is never asked to handle payments.

## Rules

- ChatGPT's verdicts are advisory. Muse owns the final call and the submission decision.
- A ChatGPT claim about a fact must be verified against an independent source before it is treated as true (it has been wrong on dates and on reading KPI tables before).
- ChatGPT is involved in every task/revision, not only when a verdict is needed.
- ChatGPT never submits, transacts, or touches account security.
